# ⚡ QUICK START (2 minutos)

## Paso 1: Abrir Terminal
Abre la terminal en la carpeta del proyecto

## Paso 2: Crear Tablas - Elige UNO:

### Opción A: Python (Recomendado)
```bash
python setup-supabase.py
```

### Opción B: Node.js
```bash
node setup-supabase-rest.js
```

### Opción C: Interactivo
```bash
node setup-interactive.js
```

## Paso 3: Instalar Dependencias
```bash
npm install
```

## Paso 4: Iniciar la App
```bash
npm run dev
```

## Paso 5: Abre en tu Navegador
```
http://localhost:3000
```

✅ ¡LISTO! Tu CRM está en funcionamiento
